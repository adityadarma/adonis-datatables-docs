# Installation

This package helps you in server side datatable management.

## Requiredment

- [AdonisJS: 6.x](https://adonisjs.com)
- [JQuery Datatables: 1.10.x](https://datatables.net)

## Installing Datatables

This package can install by allowed step.

### NPM
```shell
node ace add @adityadarma/adonis-datatables

```
or
```shell
npm install @adityadarma/adonis-datatables
```

### YARN

```shell
yarn add @adityadarma/adonis-datatables
```
